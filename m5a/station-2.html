What you change

You add a second route, /report. It reads the store and fills a template. You add one import line and three module-level names. You create the templates/ folder with report.html.

Translation row. print(...) becomes render_template("x.html", ...). The menu printed lines. The route hands values to a template. The template builds the page.

Code

Replace app.py with this file. STORE = JsonFileStore() is made once, at the top. The whole program shares it. The file also holds the problem and session that menu.py uses.

app.py 

"""Station 2: Report, a GET page. This file replaces the text menu in menu.py.

It is the only file that knows about Flask, requests, or HTML.
dataman/logic.py and dataman/store.py did not change.

Run:  python -m flask --app app run --debug --host=0.0.0.0
"""
from flask import Flask, render_template

from dataman.logic import Problem, curator_report
from dataman.store import JsonFileStore

app = Flask(__name__)

STORE = JsonFileStore()     # one store for the whole program, made once
PROBLEM = Problem("P1", "7 x 8", 56)
SESSION = "maya-1"


@app.route("/")
def home():
    return "DataMan is running on the web."


@app.route("/report")
def report():
    rep = curator_report(STORE, SESSION, PROBLEM.id)
    return render_template("report.html", session_id=SESSION, rep=rep)

Create a folder named templates next to app.py. Flask looks for templates in that folder. Put this file in it.

templates/report.html 

<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>Report</title></head>
<body>
  <h1>Curator report for {{ session_id }}: {{ rep.label }}</h1>
  <ul>
    {% for r in rep.attempts %}
      <li>try {{ r.try }}: answered {{ r.answer }} -> {{ "correct" if r.correct else "wrong" }}</li>
    {% else %}
      <li>No attempts yet.</li>
    {% endfor %}
  </ul>
</body>
</html>

How it works

  • render_template("report.html", session_id=SESSION, rep=rep) passes values to the template by keyword. The keyword is the name the template uses.
  • {{ session_id }} prints a value into the page.
  • {% for r in rep.attempts %} repeats its block for each attempt. {% else %} runs when the list is empty. {% endfor %} closes the loop.
  • The route calls curator_report from dataman/logic.py. That function did not change.

Check. The page at /report shows Curator report for maya-1: second-try success. It lists try 1: answered 55 -> wrong and try 2: answered 56 -> correct. Those attempts came from menu.py. python -m pytest -q passes.
Trap. You make attempts in menu.py while the server is already running. You reload /report and the page is old. JsonFileStore() reads the file once, when the program starts. Save app.py or stop and start the server. The reloader restarts the program, and the program reads the file again. Do not run both programs at once. Each one writes its whole copy of the store when it saves, so the last one to save erases the attempts the other one made.
Predict first

Answer. The heading shows not attempted and one line, No attempts yet. The {% else %} branch of the loop ran because the list was empty.
