"""Station 1: Hello, route. This file replaces the text menu in menu.py.

It is the only file that knows about Flask, requests, or HTML.
dataman/logic.py and dataman/store.py did not change.

Run:  python -m flask --app app run --debug --host=0.0.0.0
"""
from flask import Flask

app = Flask(__name__)


@app.route("/")
def home():
    return "DataMan is running on the web."

How the new file works

app = Flask(__name__) makes the web application. __name__ tells Flask where this file is, so it can find the templates/ folder later.

@app.route("/") is a decorator. It sits on the line above a function. It tells Flask: when a browser asks for /, call the function below.

The function returns a string. Flask sends that string to the browser. The return value is what the browser shows. There is no print().

This file has no while loop and no input(). Flask runs the loop. Your code only answers requests.
