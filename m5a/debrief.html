Self-check

These questions are for you. Nothing is scored and nothing is recorded. Answer in your own words, then open the answer.

Which file owns the two-try rule?

dataman/logic.py. MAX_ATTEMPTS = 2 is there. The web app and the text menu both ask the library. Neither one owns the rule.

What does GET promise?

A GET asks for a page and changes nothing. You can open it twice and the data is the same.

Why did the while loop disappear?

Flask's server is the loop now. It waits for a request. Each request runs one function and returns. Your code does not need to loop.

Why does practice() build a new PracticeSession on every request?

Nothing survives between requests except what the store keeps. The new PracticeSession reads the attempts from the store, so it knows the try number and whether the session is finished.

Why redirect after POST?

After the redirect, the last request the browser made is a GET. A refresh repeats a GET, and that is safe. Without the redirect, a refresh repeats the POST and spends the second try.
