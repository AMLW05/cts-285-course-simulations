Minimal Flask Starter

This starter is the controlled application you will run in your own CTS-285 repository before migrating your Module 4 product slice.

Work only in your own repository. Download these files, place them in a clearly named Module 5 folder in your CTS-285 repository, then open your repository in Codespaces.

1. Create this folder structure

minimal-flask-app/
├── app.py
├── business_logic.py
├── data_store.py
├── requirements.txt
└── templates/
    └── index.html

2. Download the starter files

Save each file with the exact filename shown. Put index.html inside the templates folder.

app.py
Flask request/response coordination
Download app.py
business_logic.py
Reusable DataMan rule behavior
Download business_logic.py
data_store.py
Temporary state boundary
Download data_store.py
requirements.txt
Flask dependency
Download requirements.txt
templates/index.html
Browser-facing template
Download index.html
README.md
Starter reference
Download README.md

3. Run it in Codespaces

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m flask --app app run --debug --host=0.0.0.0

You make the environment once. A fresh terminal starts without it, so run source .venv/bin/activate again before anything else in that terminal. python3 creates the environment, because it does not exist yet; python does everything after that.

Open the forwarded port when Codespaces offers it.

4. Establish the baseline

  1. Submit one wrong answer. You should be allowed another try.
  2. Submit another wrong answer. The correct answer should be revealed.
  3. Restart the application to reset the temporary state.

Return to Canvas for the controlled change and the questions you will use to inspect the result.
